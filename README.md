# Tecnología para Todos en Cultivos Indoor — Serie de píldoras (Nivel 0→3)

Serie divulgativa y aplicada para construir, paso a paso, un sistema de **monitorización, control y trazabilidad** en cultivos indoor.
Ejemplo conceptual: **entorno regulado** (cannabis medicinal).

> ⚠️ Contenido divulgativo centrado en tecnología, calidad y trazabilidad. Uso solo en entornos autorizados/regulados.

## Cómo usar este repositorio
1. Cada episodio vive en `episodios/<ID>/`.
2. Dentro de cada episodio encontrarás:
   - `guion.md` (texto listo para leer, con [AGRO]/[TEC]/[AMBOS])
   - `cover.txt` (texto de portada + guía rápida)
   - `caption_ig.txt` (copy para Instagram Reels)
   - `title_yt.txt`, `description_yt.txt` (copy para YouTube Shorts)
   - `pinned_comment_yt.txt` (comentario fijado)
   - `assets/` (capturas, clips, imágenes)
   - `entregables/` (plantillas/checklists del episodio)

## Estructura recomendada (escalable)
- `episodios/` — episodios individuales (carpetas)
- `templates/` — plantillas reutilizables (formularios, hojas, dashboards)
- `checklists/` — checklists (backups, seguridad, saltos de nivel)
- `docs/` — documentación larga (guía, SOPs, glosario)
- `assets/` — recursos globales (logos, overlays, portadas)

## Personalización rápida (links y placeholders)
Los archivos de copy contienen placeholders:
- `[REPO_LINK]` — URL del repositorio
- `[EP_FOLDER]` — ruta al episodio (por ejemplo: `episodios/S0E02/`)
- `[LINK_EN_BIO]` — link en bio (Instagram)

Para rellenarlos automáticamente, usa el script de esta carpeta: `customize_pack.py`.
