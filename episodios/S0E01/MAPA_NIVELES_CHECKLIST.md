# 🗺️ Mapa de Niveles: Ruta de Digitalización de Cultivos

Este documento acompaña al **Episodio S0E01** de la serie. Aquí definimos qué significa cada nivel para que ubiques dónde estás y hacia dónde vas.

> **Regla de Oro:** No intentes saltar niveles. La automatización de un proceso caótico solo genera caos automatizado.

---

## 🪜 La Escalera 0 → 3

### 🟢 Nivel 0: El Cimiento (Manual y Estricto)
* **Objetivo:** Disciplina y consistencia de datos.
* **Herramientas:** Papel, formularios digitales básicos (Google Forms/Excel).
* **El dato:** Se registra a mano.
* **La meta:** Definir QUÉ medir y CÓMO medirlo. Si no lo haces bien aquí, la IA del Nivel 3 fallará.

### 🔵 Nivel 1: El Ojo Digital (Sensores IoT)
* **Objetivo:** Continuidad y precisión.
* **Herramientas:** Sensores IoT (ESP32, Zigbee, Bluetooth).
* **El dato:** Se genera automáticamente las 24h.
* **La meta:** Eliminar los "huecos" de datos de la noche y fines de semana.

### 🟣 Nivel 2: El Cerebro Local (Plataforma)
* **Objetivo:** Centralización y soberanía.
* **Herramientas:** Home Assistant, Grafana, Raspberry Pi / Mini PC.
* **El dato:** Es propiedad tuya. Se almacena en local.
* **La meta:** Ver todos los datos (manuales + sensores) en un solo cuadro de mando.

### 🟠 Nivel 3: La Inteligencia (IA y Predicción)
* **Objetivo:** Asistencia y optimización.
* **Herramientas:** LLMs (Modelos de Lenguaje), Agentes de IA.
* **El dato:** Se usa para "razonar".
* **La meta:** Que el sistema te avise de anomalías complejas.

## ✅ Checklist de Inicio: ¿Dónde empiezo?

Marca las casillas para saber si estás listo para graduarte del Nivel 0:
- [ ] Tengo definidos los nombres de mis fases (ej: "Vegetativo", "Floración").
- [ ] Tengo una lista única de variables (ej: siempre uso "temp_amb", no "temperatura").
- [ ] Registro datos todos los días sin falta.

### 👥 Perfiles de Usuario (Comenta en el video)
* **🅰️ Perfil A (Plug & Play):** Quieres que funcione. Dispuesto a pagar por facilidad.
* **🅱️ Perfil B (Vibecoding):** Quieres control total y bajo coste. Te gusta el código.
* **©️ Perfil C (Low-Code):** El equilibrio. Configurar sí, programar no tanto.
